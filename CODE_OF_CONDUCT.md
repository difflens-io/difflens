# Code of Conduct

DiffLens welcomes constructive participation from people with different backgrounds and experience levels.

## Expected Behavior

- Be respectful and specific in discussions.
- Focus technical feedback on code, behavior, reproducibility, and user impact.
- Assume public issues and pull requests are permanent project records.
- Keep privacy and security concerns private when they include sensitive details.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information without permission.
- Repeated off-topic disruption of project spaces.
- Sharing exploit details publicly before maintainers have had a chance to respond.

## Enforcement

Project maintainers may edit or remove comments, close issues, reject contributions, or limit participation when behavior conflicts with this code of conduct.

Report serious conduct issues privately through the repository owner's public contact channel or GitHub reporting tools.
